#### Display

- **Borderless Windowed** - runs the game in a borderless window at the desktop resolution using the engine's native borderless mode
- **FPS Limiter** - caps the game's frame rate using the built-in engine limiter

#### Graphics

- **Anisotropic Filtering** - forces the selected anisotropic filtering level on all textures
- **Console Gamma** - restores the Xbox 360's darker gamma with deeper blacks and stronger contrast
- **Ambient Occlusion** - enables screen space ambient occlusion (SSAO) for darker contact shadows - creases and foliage shading (DirectX 9 renderer only)
- **Enhanced LODs** - pushes back the distance at which models - terrain detail - trees and clusters drop to lower detail or stop drawing
- **Enhanced Shadow Range** - longer and softer sun shadows - more vegetation casting them - and static ambient shadows kept much further out
- **Shadow Resolution** - raises the sun and cascaded shadow map resolution

#### Gameplay

- **Remove Mouse Speed Cap** - removes the engine's mouse movement speed limit
- **Mouse Look Sensitivity** - adjusts mouse look sensitivity beyond the in-game slider
- **Sprint Turn Modifier** - controls how much horizontal look speed is reduced while sprinting
- **Aim Toggle** - tap to aim down sights instead of holding the button
- **Sprint Toggle** - tap to sprint instead of holding the button
- **Limited Saving** - enables console-style saving by removing Save Game from the pause menu and disabling F5/F9 quick save/load
- **Console Autosaves** - displays the save box after mission completion - matching the console versions
- **No Blinking Items** - prevents weapons - ammo - health boxes - diamond cases - beds and other interactables from flashing

#### Field of View

- **Field of View** - adjusts the base gameplay field of view
- **Viewmodel Field of View** - changes the first-person weapon and arms field of view
- **Ironsight Field of View** - adjusts the field of view while aiming down sights without affecting magnified scopes
- **Vehicle Field of View** - adjusts the field of view while driving

#### Controller

- **Controller Look Sensitivity** - adjusts controller look sensitivity beyond the in-game slider
- **Aim Assist** - enables or disables controller aim assist
- **Vibration** - restores controller vibration support
- **Aim Toggle** - tap to aim down sights instead of holding the button

#### Content Unlocks

- **Predecessor Tapes Unlock** - unlocks the seven predecessor tape missions that were gated behind an online entitlement
- **Machetes Unlock** - unlocks the Primitive and Homemade machete skins

#### General

- **Skip Intro** - skips the Ubisoft - Dunia and rating screens during startup
- **Skip Title Screen** - boots directly to the main menu
- **CPU Affinity** - limits the game to the first logical processor for compatibility
- **High Precision Timer** - enables a 1 ms timer resolution for smoother loading screen progress
- **Skip System Detection** - skips redundant hardware detection during startup
- **Large Address Aware** - patches the executable to increase the memory limit from 2 GB to 4 GB
